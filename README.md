# Tic-Tac-Toe AI

A terminal-based Tic-Tac-Toe game written in **C++17**. Play as X against an AI that uses the minimax algorithm.

## Features
- Human vs computer gameplay
- Minimax decision-making
- Input validation and win/draw detection

## Build and run
Requires a C++17 compiler and CMake 3.16+.

```bash
cmake -S . -B build
cmake --build build
```

Run `build/tictactoe` on Linux/macOS or `build\Debug\tictactoe.exe` on Windows with Visual Studio.

## Controls
Enter a number from 1 to 9 to place X in the corresponding square. The AI plays O.
